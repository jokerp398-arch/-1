3.2 Для чего нужен корневой каталог / и какие важные системные каталоги вы знаете?
Он нужен для выполнения команд пользователя и взаимодействия с OC /etc /usr /bin и тд

3.3 Чем абсолютный путь отличается от относительного? Приведите примеры.
Абсолютный путь начинается от корневого каталога / и полностью указывает расположение файла пример абсолютного: /home/user/file.txt пример относительного: docs/file.txt

3.4 Какие символы используются для обозначения текущего, родительского и
домашнего каталогов? . - текущий каталог .. - родительский каталог ~ - домашний каталог Пример: cd .. cd ~

3.5 Какая команда используется для рекурсивного копирования каталогов?
используется команда cp -r Пример: cp -r folder1 folder2

3.6 В чём разница между командами rmdir и rm -r?
rmdir удаляет только пустые каталоги rm удаляет каталог вместе с его содержимым

3.7 Как изменить права доступа на файл, чтобы его можно было выполнять как
скрипт? использовать: chmod +x имя_файла После этого файл можно запустить .script.sh

3.8 Что выведет команда ls -l и как расшифровать её вывод
выводит подробную информацию о файлах и каталогах: права доступа количество ссылок, владельца, группу, размер, дату изменения и имя.

3.9 Как получить справку по неизвестной команде?
использовать man команда пример: man ls

3.10 Что произойдёт, если выполнить cd / и затем rm -rf *
cd / перейдёт в коренвой каталог файловой систем. после ls -l будет показано содержимое корневого каталога

3.11 Назовите два режима работы vi/vim. Как переключаться между ними
Два основныъ режима

командный режим- выполнение команд Vim
Режим вставки- ввод и реактирование текста
3.12 Как в vi/vim перейти в начало файла, в конец файла, на строку с заданным
номером начало файла gg конец файла G перейти на определённую строку :номер

3.14 Как скопировать строку и вставить её ниже?
Поставить курсор на нужную строку и нажать уу затем нажать p

3.15 Как выполнить поиск и замену текста во всём файле
Используя команда :%s/старый текст/новый текст/g
